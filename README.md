# Face-recignition-system
Система распознавания лиц (детекция + выравнивание + распознавание)
## 📌 Описание проекта

Этот проект посвящен созданию системы распознавания лиц. В репозитории представлены Jupyter ноутбуки, которые реализуют полный пайплайн обработки: от детекции, разметки ориентиров и выравнивания лиц с помощью аффинного преобразования до получения эмбеддингов лиц для распознавания по косинусному сходству. В качестве детектора использовался mtcnn; выравнивание лиц происходит путем предсказывания heatmap'ов разметки (landmarks), для чего была реализована архитектура StackedHourglass, и последующего поворота аффинным преобразованием; извлечение эмбеддингов лица для распознавания реализуется предобученным на ImageNet efficientnetb0. Модель для распознавания способна различать как уже знакомые лица, так и совершенно новые, которые она не видела.

Для работы были отобраны изображения из CelebA_Dataset, их 22000. Важно отметить, что в данном проекте использовались именно "сырые" изображения (не обрезанные и не выровненные). Проект включает в себя все этапы работы с датасетом CelebA, а именно: его фильтрацию, разделение на выборки train/val. В репозитории присутствуют скрипты для отбора изображений и их обрезки по bounding box'ам. Выбранные мной изображения - в файле selected_faces.csv. Также здесь приложен скрипт для пересчета координат разметки для уже обрезанных изображений.

Ссылка на датасет CelebA - https://mmlab.ie.cuhk.edu.hk/projects/CelebA.html

## 🔧 Основные компоненты

FaceAlignment.ipynb: Этот ноутбук отвечает за выравнивание лиц на основе предсказанных ориентиров (landmarks)
FaceRecognition_and_ArcFace.ipynb: Содержит код для построения и обучения модели распознавания лиц, а также её тестирование
FR_full_pipeline.ipynb: Объединяет все этапы в один полный пайплайн для удобного запуска
Скрипты (.py): Вспомогательные скрипты для предварительной обработки данных (фильтрация, обрезка, работа с разметкой)

## 🚀 Старт

### Требования

Для запуска ноутбуков вам понадобится:

-   Установленный Python 3.12
-   Google Colab / Jupyter Notebook или Jupyter Lab
-   Библиотеки, перечисленные в файлах ноутбуков (`pytorch`, `pandas`, `numpy` и др.)
-   Скачанный CelebA_Dataset

### Запуск

При первом запуске ноутбуков убедитесь, что все необходимые библиотеки установлены. Пути к данным в ноутбуках и скриптах могут потребовать корректировки в зависимости от того, где вы храните датасет и прочие материалы.

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/ihavenoreflection/Face-recognition-system.git
    cd Face-recognition-system
2.  Скачайте CelebA_Dataset (папки anno и eval тоже)
3.  Отберите изображения для работы и разделите на train/val (для этого скрипт и файл selected_faces.csv) - выйдет две папки
4.  Запустите script_crop.py - получатся еще две папки (предыдущие две можно удалить), их архивируйте, положите архивы в корневую папку проекта (FR_project) на google disk
5.  Запустите script_landmarks_cropped.py - он сделает папку с пересчитанными координатами изображений, ее переместите на google disk в папку проекта
6.  Положите на google disk в папку проекта три ноутбука, запускайте ячейки FaceAlignment - результат: в папке проекта обученная StackedHourglass и папка с выровненными лицами, разбитыми на выборки
7.  Положите в папку проекта файл identity_celebA.txt (из anno), запустите FaceRecognition_and_ArcFace - в папке появятся обученные модели для распознавания
8.  Запуск FR_full_pipeline - демонстрация работы (как модель отличает любые лица друг от друга), в качестве тестового фото можно взять любое фото с лицами людей
